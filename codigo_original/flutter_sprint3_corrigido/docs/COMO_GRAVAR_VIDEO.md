# Como gravar o vídeo de funcionamento

Grave um vídeo curto, entre 1 e 3 minutos, com o aplicativo rodando no emulador Android ou dispositivo físico.

Mostre este fluxo:

1. Tela inicial;
2. Pré-triagem;
3. Lista de bancos de leite;
4. Detalhe de uma unidade;
5. Agendamento;
6. Confirmação;
7. Acompanhamento;
8. Orientações.

Depois de publicar o vídeo, coloque o link no campo **Vídeo de demonstração** do README.md.
